# NYC Arrest, Poverty, and Education Spatial Correlation Project

This repository contains ongoing work and R scripts for analyzing spatial correlations between arrest rates, poverty, and education in NYC.  

## Contents

- R scripts (`.R`)
- R Markdown files (`.Rmd`)
- Data files used for analysis (not included)

## Description

The project explores relationships between socio-economic indicators and crime statistics across NYC neighborhoods using spatial analysis techniques. The scripts include data cleaning, visualization, and correlation analysis.

## Usage
1. Open the R scripts or R Markdown files in RStudio.
2. Run the code to reproduce the analyses.
3. Data files (not included) should be stored in the appropriate subfolders as referenced in the scripts.
